# Tests

## Inputs
- Python scripts from `../scripts/`
- Backend integration dependencies (OpenCode)

## Process
Test suite for validating project scripts, schemas, templates, and backend integrations:
- `test_opencode_backend.py`: OpenCode integration and backend execution checks.
- `test_document_adoption.py`: Template drift and funnel block compatibility checks.
- `test_schemas_and_config.py`: Schema validity, capability vocabulary, and config template checks.
- `test_config_and_indexing.py`: Configuration fallback and dynamic indexing checks.

## Outputs
- Test results and coverage reports
