# Scripts

## Inputs
- `../config.local.yaml`: Local configuration
- `../criteria.yaml`: Evaluation criteria
- `../capabilities.yaml`: Capability vocabulary
- `oss_config.py`: Configuration loader

## Process
Core workflow scripts for the pipeline (run via `run.py` or individually):

- **run.py**: Orchestrator. Runs the full pipeline: fetch → pack → judge → index in one command.
- **scout.py**: Fetch stage. Collects GitHub metadata without calling an LLM.
- **pack_repos.py**: Pack stage. Clones repos and creates commit-pinned evidence snapshots (README + code).
- **judge_loop.py**: Judge stage. Evaluates repos against criteria using LLM backends (OpenCode or Claude).
- **build_index.py**: Index stage. Rebuilds INDEX*.md files from judged repos/*.md notes.

Other scripts in this folder are utilities, experiments, or helper tools.

### OpenCode Model Rotation Workflow
1. **Find exact slug**: Run `opencode models` and filter for your keyword (e.g., `opencode models | grep -i "<keyword>"` or `Select-String` in PowerShell). Verify the slug before updating configuration.
2. **Update configuration**: Set `model: <slug>` in `config.local.yaml` (and `config.example.yaml` if updating the shared template).
3. **Verify single note**: Run `python scripts/judge_loop.py <target> --force --limit 1` or `python tests/test_opencode_backend.py`.
Avoid manual echo tests or testing deprecated models.

## Outputs
- `../inbox/*.md`: Repo digests awaiting triage (generated by scout.py)
- `../knowledge/repos/*.md`: Evaluated repo notes with judge verdicts
- `../knowledge/INDEX*.md`: Generated summary index files (built by build_index.py)
