# Current Project

## What we are building
OpenSourceScout is a scouting framework for open source projects. It is designed to find, evaluate, and analyze open source repositories based on defined criteria and targets.

## What good looks like
- Clean, modular, well-documented code.
- Reliable execution for parsing methodologies and scoring repositories.
- Interpretable folder-structure based AI context generation.

## What to avoid
- Over-engineering simple tasks.
- Copy-pasting boilerplate without understanding it.
- Hardcoding sensitive data or API keys into scripts.
